# NetQuality — نسخه 1.2

اپلیکیشن اندرویدی بررسی و پایش کیفیت اینترنت؛ شامل اطلاعات اتصال، Ping، Jitter، Packet Loss، DNS، دسترسی سایت‌ها، تست سرعت و Trace/TCP Ping.

## امکانات نسخه 1.2
- آیکون اختصاصی اندروید با تم مانیتورینگ شبکه
- گزارش‌های تفکیک‌شده و خواناتر
- تب مستقل نمودار زنده
- سه نمودار مجزا برای Ping، Jitter و Packet Loss
- محاسبه Jitter به‌صورت اختلاف مطلق تأخیر دو پاسخ متوالی
- نمایش Packet Loss تجمعی در طول نمونه‌برداری
- تنظیم Refresh از ۱ تا ۶۰ ثانیه؛ هر سه نمودار با همین فاصله به‌روزرسانی می‌شوند
- خروجی اشتراک‌گذاری گزارش تست و گزارش Trace

> نمودارها هنگام اجرای تست در تب «تریس / پلاتر» به‌روزرسانی می‌شوند. نمودار Ping و Jitter برحسب میلی‌ثانیه و Packet Loss برحسب درصد است. در حالت Trace، نمودارها مربوط به آخرین هاپ پاسخ‌دهنده هستند.

## ساخت APK با GitHub Actions
1. فایل ZIP را استخراج کنید.
2. تمام محتویات پوشه پروژه (از جمله پوشه مخفی `.github`) را مستقیماً در ریشه یک Repository جدید GitHub بارگذاری کنید؛ نباید یک پوشه اضافی دور فایل‌ها باقی بماند.
3. در GitHub وارد تب **Actions** شوید و Workflow با نام **Build APK** را باز کنید.
4. روی **Run workflow** بزنید؛ یا پس از بارگذاری فایل‌ها، اجرای خودکار Workflow را از فهرست اجراها باز کنید.
5. پس از موفقیت، پایین صفحه اجرای Workflow در قسمت **Artifacts** فایل **NetQuality-APK** را دانلود کنید.
6. ZIP مربوط به Artifact را باز کنید؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید.

## پیش‌نیازها
- Android Studio / Android Gradle Plugin 8.5.2
- Gradle 8.7
- JDK 17

این مخزن Workflow آماده GitHub Actions دارد و برای ساخت APK در GitHub نیازی به نصب Android Studio روی گوشی نیست.
