# NetQuality 1.3

اپلیکیشن اندرویدی بررسی کیفیت اتصال و عیب‌یابی دسترسی شبکه.

## قابلیت‌ها
- تست وضعیت اتصال، Gateway، Ping، Jitter و Packet Loss
- بررسی DNS و دسترسی HTTP/HTTPS سایت‌های داخلی و بین‌المللی
- تست سرعت دانلود
- Traceroute با ICMP و TCP Ping به همراه نمودار زنده
- نمودارهای مستقل Ping، Jitter و Packet Loss و تنظیم فاصله Refresh از ۱ تا ۶۰ ثانیه
- بخش تشخیص محدودیت دسترسی برای Facebook، Instagram، YouTube، Telegram، X، WhatsApp و دامنه دلخواه
- رابط کاربری با کارت‌های روشن، فاصله‌گذاری بیشتر و تم سرمه‌ای/فیروزه‌ای

## ساخت APK با GitHub Actions
1. تمام محتویات این پوشه را در ریشه Repository قرار دهید؛ پوشه `.github` نیز باید حفظ شود.
2. از تب Actions، گردش‌کار Build APK را اجرا کنید (یا با Push خودکار اجرا می‌شود).
3. پس از موفقیت، Artifact با نام `NetQuality-APK` را دریافت کنید.

## نکته درباره تشخیص فیلترینگ
این بخش DNS، اتصال TCP به پورت 443، اتصال کنترلی به 1.1.1.1 و پاسخ HTTPS را بررسی می‌کند. خروجی «احتمال محدودیت» تشخیص قطعی نیست؛ اختلال مقصد، DNS، TLS، CDN یا سیاست خود وب‌سایت نیز می‌تواند نتیجه مشابه ایجاد کند. برای مقایسه اپراتورها، آزمون را جداگانه روی هر اتصال اجرا کنید. برنامه در هر اجرا فقط از شبکه فعال گوشی استفاده می‌کند و امکان انتخاب/اتصال خودکار به اپراتور دیگر ندارد.

## ساختار

- `.github/workflows/build.yml`: ساخت خودکار APK
- `build.gradle.kts` و `settings.gradle.kts`: تنظیمات Gradle
