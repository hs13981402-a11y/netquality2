# NetQuality 1.4

نسخه 1.4 بر پایه نسخه 1.3 ساخته شده و قابلیت‌های قبلی را حفظ می‌کند.

## بهبودهای این نسخه
- تفکیک بصری بهتر بخش‌های گزارش تست کامل با تیترهای برجسته و فاصله‌گذاری خواناتر
- بازطراحی پنجره گزارش‌های ذخیره‌شده به‌صورت کارت‌های مجزا، با امکان اشتراک‌گذاری همه گزارش‌ها و پاک‌سازی همراه با تأیید
- نمایش مقادیر آخرین نمونه و میانگین/وضعیت زیر عنوان نمودارهای Ping، Jitter و Packet Loss
- خواناتر شدن جدول مسیر و فاصله‌گذاری نمودارها

## ساخت APK
در GitHub Actions گردش‌کار موجود در `.github/workflows/build.yml` را اجرا کنید. خروجی Debug APK در مسیر زیر تولید می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

Package: `com.netquality.app`
Version: `1.4` (versionCode 5)
